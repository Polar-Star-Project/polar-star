# Polar Star (Estrella Polar)

Navigate immigration detention and find your family. Free. Never commercial. Not affiliated with any government agency.
Published by the Polar Star Project.

This repository is the published copy of the Polar Star page and the data it shows:

- `site/` — the page as published at polarstarproject.org.
- `data/` — the data files behind the page. Each citation on the page links here at the data version it was built
  from (tags named `data-YYYY-MM-DD-rN`).
- `LICENSE` (software), `LICENSE-CONTENT` (written content), `LICENSE-DATA` (data).

Each published version is one commit. Corrections and replies: see the page's corrections section.
